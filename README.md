# Group 7 Project

# Mô tả dự án
Đây là dự án quản lý người dùng đơn giản, cho phép thực hiện các thao tác CRUD (Create, Read, Update, Delete) trên thông tin người dùng. Dự án được xây dựng với kiến trúc full-stack: frontend sử dụng React, backend sử dụng Node.js với Express, và cơ sở dữ liệu MongoDB.

# Công nghệ sử dụng
# Frontend
- React
- Axios
- CSS 

# Backend
- Node.js
- Express.js
- MongoDB với Mongoose
- Dotenv

# Database
- Git & GitHub
- MongoDB Atlas
- Postman

# Hướng dẫn chạy dự án
# Backend
- ```bash
- cd backend
- npm install
- npm start
- Mặc định chạy tại http://localhost:3000
# Frontend
- cd frontend
- npm install
- npm start
- Mặc định chạy tại http://localhost:3001
